# CodeIDE — Мобильная среда разработки для Android

**CodeIDE** — это полноценная мобильная IDE для Android, вдохновлённая IntelliJ IDEA и VS Code. 

## Возможности
- 📁 **Управление проектами**: Создание проектов по шаблонам ("Пустая папка", "Kotlin приложение", "Python скрипт", "Web (HTML/CSS/JS)") и открытие существующих локальных проектов через Android Storage Access Framework (SAF).
- 🌲 **Дерево файлов**: Полный файловый менеджер проекта с поддержкой `.gitignore`, контекстным меню (создание, переименование, удаление), перемещением и вкладочной системой проектов.
- 📝 **Редактор кода**: Подсветка синтаксиса (Kotlin, Java, Python, JS/TS, HTML, CSS, XML, JSON, Gradle, Markdown), нумерация строк, сворачивание блоков кода, подсветка парных скобок, автоотступы, перенос строк (Word Wrap), автодополнение и поиск/замена.
- ⚠️ **Диагностика проблем (Problems)**: Проверка синтаксиса в реальном времени, вкладка "Problems" с переходом к строке ошибки.
- ⚙️ **Настройки**: Мгновенное изменение размера шрифта (8-24sp), переключение тем (Darcula / Light), экспорт/импорт тем в JSON, настройка API-ключа OpenCode и Git-профиля.
- 🤖 **OpenCode AI-ассистент**: Чат с ИИ для генерации и объяснения кода, отправка выделенного фрагмента кода в чат, предварительный просмотр изменений (Diff Preview) с кнопками «Применить» / «Отклонить».
- 💻 **Встроенный терминал**: Выполнение shell-команд в директории проекта, быстрые кнопки (`ls`, `pwd`, `git status`, `git log`), история команд.
- 🔀 **Интеграция с Git**: Клонирование репозиториев, просмотр изменённых файлов (M/A/D), совершение коммитов, push/pull и просмотр истории коммитов.

## 🚀 Инструкция по сборке APK через GitHub Actions

### Шаг 1. Загрузка репозитория на GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Выполните следующие команды в терминале:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of CodeIDE"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.NNAME.git
   git push -u origin main
   ```

### Шаг 2. Запуск сборки
После выполнения `git push` GitHub Actions автоматически запустит рабочий процесс сборки APK (файл `.github/workflows/build.yml`).

### Шаг 3. Скачивание готового APK
1. Перейдите во вкладку **Actions** в вашем GitHub репозитории.
2. Выберите последний запущенный workflow (`Build CodeIDE APK`).
3. Дождитесь успешного завершения сборки (зелёная галочка).
4. В блоке **Artifacts** (внизу страницы сборки) скачайте архив `CodeIDE-Debug-APK`.
5. Распакуйте архив и установите `app-debug.apk` на ваше Android-устройство.

## 🛠 Технологии
- **Kotlin** + **Jetpack Compose** (Material 3)
- **Room Database** (Хранение проектов, истории терминала и чата)
- **DataStore Preferences** (Сохранение настроек редактора и тем)
- **JGit** (Локальные Git-операции)
- **OkHttp** / **Retrofit** (Связь с API OpenCode AI)
